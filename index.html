3. JavaScript Asíncrono (Fetch & Async/Await)

Manejo de peticiones HTTP de forma segura con manejo de errores expresivo.

JavaScript 
async function fetchUserData(userId) {
    try {
        const response = await fetch(`https://api.ejemplo.com/users/${userId}`, {
            headers: { 'Accept': 'application/json' }
        });

        if (!response.ok) {
            throw new Error(`Error HTTP: ${response.status}`);
        }

        const data = await response.json();
        return data;
    } catch (error) {
        console.error('Fallo al obtener usuario:', error);
        throw error;
    }
}

2. React Server Components & Next.js App Router

Ejemplo de un Server Component en Next.js fetching datos en el servidor sin clientes bundle JS extra.

TSX (Next.js) 
// app/users/page.tsx (Server Component por defecto)
import { Suspense } from 'react';

async function UserList() {
    const res = await fetch('https://api.ejemplo.com/users', { cache: 'no-store' });
    const users = await res.json();

    return (
        <ul className="space-y-2">
            {users.map((u: any) => (
                <li key={u.id} className="p-3 bg-slate-800 rounded">{u.name}</li>
            ))}
        </ul>
    );
}

export default function UsersPage() {
    return (
        <section>
            <h1 className="text-2xl font-bold">Usuarios</h1>
            <Suspense fallback={<p>Cargando datos del servidor...</p>}>
                <UserList />
            </Suspense>
        </section>
    );
}

Capítulo 05

Rendimiento Web & Core Web Vitals

Métricas fundamentales de Google (LCP, INP, CLS) y técnicas prácticas para lograr puntajes de 100 en Lighthouse.

1. Metricas Core Web Vitals (2026)

    LCP (Largest Contentful Paint): Mide la velocidad de carga percibida. Meta: < 2.5s. INP (Interaction to Next Paint): Reemplaza a FID. Mide la responsividad general ante interacciones del usuario. Meta: < 200ms. CLS (Cumulative Layout Shift): Mide la estabilidad visual evitando cambios repentinos. Meta: < 0.1.

2. Carga Diferida (Lazy Loading) de Imágenes y Componentes

JavaScript / HTML 
<!-- Imagen con Lazy Loading Nativo e hint de prioridad -->
<img src="hero-banner.webp" fetchpriority="high" alt="Banner principal" />
<img src="footer-image.jpg" loading="lazy" decoding="async" alt="Imagen secundaria" />

<!-- Code Splitting en React -->
import { lazy, Suspense } from 'react';
const ChartHeavy = lazy(() => import('./ChartHeavy'));

function Dashboard() {
    return (
        <Suspense fallback={<div>Cargando gráfico...</div>}>
            <ChartHeavy />
        </Suspense>
    );
}
